# NH05 ladies-watch fit verification checklist

Prepared 4 October 2026 from the TMI NH05B specification sheet and dated supplier research. All measurements are millimetres unless stated otherwise. This checklist does not certify fit by itself.

## Identify the exact parts first

- [ ] Record case supplier, URL, exact colour/bezel/bracelet variant, SKU, package contents and drawing revision.
- [ ] Record dial supplier, variant, date position and SKU.
- [ ] Record full three-hand set supplier, finish and SKU; charge its price once, not once per hand.
- [ ] Confirm the actual movement is NH05B, not NH35, and record the centre-post/hand-height type.
- [ ] Record source, check date, drawing page or photograph, instrument resolution, measurement uncertainty and reviewer for every value below.

Use a digital caliper for exterior dimensions, a depth gauge for shoulders and a microscope/pin gauges or a watchmaker for small bores. Calipers alone cannot reliably verify a 0.213mm seconds-hand fitting. Do not force hands onto posts or machine parts to make them fit.

For each measurement record: `actual value | tolerance/uncertainty | source + date | result (pass/fail/unknown)`. Blank values are unknown, not zero.

## Published reference - not supplier measurements

[TMI NH05B specification PDF](https://timemodule.com/upload/category/21/spec_sheet/NH05_SS.pdf), pages 5-10. Drawings use hundredths of a millimetre: divide their numeric dimensions by 100.

| Interface | TMI reference |
| --- | --- |
| Movement OD / casing OD | 17.50 / 17.20 nominal; use drawing tolerances |
| Dial support OD / height with support | 19.80 / 5.92 |
| Type M total maximum height including movement | 7.604 |
| Hour / minute / seconds post fitting | 1.100 (+0.006/-0) / 0.656 +/-0.005 / 0.213 +/-0.005 |
| Maximum hand tip radius | 9.50 |
| Type M hand levels A/B/C from dial | 0.62 / 1.01 / 1.37; review complete page-6 stack drawing |
| Reference dial thickness / centre opening | 0.40 / 1.65 +/-0.05 |
| 3 o'clock date aperture | 1.85 wide x 1.30 high; centre radius 6.825 |
| Dial feet F1 / F2 | (+7.4810, +3.4790) / (-8.0842, -1.6450), +y toward 12 o'clock |
| Dial feet diameter / length | 0.64 (+0.015/-0.010) / 2.00 (+0.05/-0.10) |
| Casing ring OD / movement seat | 19.80 (-0.02/-0.07) / 17.55 (+0.05/-0.01) |

The post fitting dimensions above are NOT measured hand-bore dimensions. Hand bores and their interference fits need the hand manufacturer's specification or a watchmaker's verification.

TMI's reference dial OD is 19mm. A supplier's 24.5mm aftermarket dial can overhang the support, but this does not prove its feet, thickness, date layout or case-seat fit.

## A. Case and movement holder

Supplier case candidate: [34mm Tandorio NH05 case](https://tandoriowatch.com/products/34mm-nh05-watch-case-bezel-insert-ring-sapphire-glass). Supplier says 34mm OD, 12mm thickness and 24.2-25mm dial range; photo labels 24.5mm. These are headline dimensions, not tolerance drawings. Do not copy the old provisional GLB's 10.5mm thickness or inferred internal interfaces into this product.

- [ ] Actual case OD and thickness, with supplier's inclusion/exclusion of back, crystal and protrusions recorded.
- [ ] Internal movement cavity diameter and usable depth, measured at every relevant shoulder.
- [ ] Actual movement-holder ID, OD, shoulder depth, retention method and stem cut-out.
- [ ] Dial-seat diameter, supporting shoulder width and axial depth.
- [ ] Rehaut opening diameter and overlap with the dial edge.
- [ ] Stem-axis height from the same dial-support datum and crown-tube orientation; check movement and case axes align without strain.
- [ ] Crystal underside height from that datum, across the full swept hand area; include gasket compression and any domed/magnifier low point.
- [ ] Caseback-to-rotor clearance with holder and back installed.
- [ ] Crown/stem engagement, winding and setting travel verified by a watchmaker; the drawing's reference stem length is not a pre-cut finished-case stem length.

Pass only with matching measured mating dimensions and tolerances, adequate running clearances and secure retention. Overall 12mm case thickness is not usable internal cavity depth. Diameter alone cannot confirm movement fit.

## B. Actual supplier dial

Candidate: [24.5mm white matte NH05 dial](https://tandoriowatch.com/products/24-5mm-watch-dial-nh05-white-matte-dial?variant=50672056467741). Supplier publishes OD and 3 o'clock date only; the app's nominal 0.4mm thickness is a clearly labelled presentation placeholder.

- [ ] OD, thickness and flatness measured, with tolerances.
- [ ] Centre opening size and alignment measured against the reference.
- [ ] Both feet positions (x/y), diameter, length and retention engagement match the actual NH05B movement.
- [ ] Date aperture centre, width, height and orientation match the movement; date remains readable through all dates, not just one.
- [ ] Dial sits flat on its intended support, is retained securely and clears the rehaut.
- [ ] Maximum applied-marker/lume height recorded in every swept-hand region.
- [ ] Rear dial features/feet do not interfere with movement parts.

Do not remove feet or approve adhesive mounting silently. Such changes require a separate modification plan and risk review.

## C. Actual hands

Candidate: [Tandorio NH05 luminous set](https://tandoriowatch.com/products/nh05-hands-silver-blue-black-gold-rosegold-watch-hands-green-luminous). Published centre-to-tip lengths are 5/8/8mm. Silver, gold, black, blue and rose-gold finishes are advertised, not guaranteed stock.

- [ ] Hour/minute/seconds centre-to-tip lengths measured separately; each <=9.50mm TMI maximum and inside the actual dial/rehaut envelope.
- [ ] Counterweight radius, width, thickness, tube height and underside offsets measured for each hand.
- [ ] Each bore fit verified against its correct post without forcing; NH35 hand sizes must not be substituted.
- [ ] Axial hand-stack levels measured from the same dial datum; verify dial/lume-to-hour, hour-to-minute and minute-to-seconds running gaps.
- [ ] Hand-to-crystal clearance checked across a complete sweep, including counterweights, crystal low points and tolerance stack-up.
- [ ] Full rotation has no collisions, rubbing, slip or distorted tubes; check setting and running operation.
- [ ] Unbalance meets TMI limits (hour 100, minute 75, seconds 11 mg.mm), or obtain manufacturer's evidence/watchmaker's professional assessment before certification.

A separate advertised 6.5/10/10mm set exceeds the published 9.5mm maximum tip radius. Do not approve it just because the seller calls it NH05-compatible.

## D. Approval and records

- [ ] Every critical value above has a source and uncertainty; no critical blank remains.
- [ ] Apply worst-case tolerances to each mating fit and clearance. Positive nominal clearance alone is not sufficient; use manufacturer's permitted fit/clearance or obtain professional assessment where limits are unspecified.
- [ ] Resolve any failed fit by choosing a measured compatible component, not by changing the recorded evidence.
- [ ] Record exact approved part IDs and verification date; only then promote the corresponding catalogue entry from draft/unverified.
- [ ] Keep commercial stock and delivered price checks separate: item + South African shipping + applicable taxes/duties, selected variant and timestamp.
- [ ] GLB presentation accuracy is separately assessed; photographs and visual matches do not certify hidden interfaces.
- [ ] Water resistance requires appropriate assembled-watch pressure testing, not supplier text or this dimensional checklist.
