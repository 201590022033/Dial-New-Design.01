4. SHARED MATHEMATICAL REQUIREMENTS

Both systems must use two concentric main calculation scales:
• An outer rotating scale.
• An inner fixed scale.

Both main scales cover one logarithmic decade, from 10 through values below 100, returning to the shared 100/10 position.

Calculate every numerical graduation using:

angle(value) = origin + direction × 360 × log10(value / 10)

Use identical logarithmic angular geometry and increasing direction for both scales.

Their radii can differ. Their mathematical angular spacing cannot differ.

Determine the fixed scale origin and direction from the selected original reference. Apply bezel rotation only to the rotating group.

Do not:
• Space numerical labels uniformly around the circle.
• Space subdivisions uniformly between endpoints.
• Treat the main slide rule as a conventional 60-minute bezel.
• Add a duplicate physical tick at the shared 100/10 position.
• Copy malformed numbers or geometry from my mock-up.

Equal numerical ratios must produce equal angular differences. For example:
• 20 to 40 has the same angular separation as 30 to 60.
• 30 to 60 spans approximately 108.371°, not 180°.

Match the original printed labels. If the original abbreviates a value, such as printing 7 to represent 70, retain the correct underlying mathematical value.
