# Manufacturing Guide

## Validation Coverage

Current validation includes:
- minimum line width
- text legibility and text-too-small warnings
- laser kerf checks
- UV print minimum checks
- overlaps and invalid concentric geometry
- printable area overflows
- tolerance range validation
- collision-mapped warnings

## Material Considerations

Material library includes:
- thickness
- laser suitability
- UV suitability
- CNC suitability
- color options
- recommended tolerance
- process notes

## Export Readiness

Use Export Preview before final output:
- verify dimensions
- inspect layer list and materials
- inspect warnings
- review estimated print/engraving/laser sizes
