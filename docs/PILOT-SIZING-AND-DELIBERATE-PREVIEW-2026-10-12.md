# Pilot sizing and deliberate option previews

Rotating bezel resizing now retains each authored radial lane within its annulus instead of resetting tick placement to the outer lip. The independently bound fixed scale is unchanged. This applies to Simplified, Citizen and Navitimer.

All three live/export slide-rule engines use a 1.15 graduation baseline for tick length and stroke width. Angular calibration and station counts are unchanged; user length factors remain adjustable. Decimal-hour dial lettering defaults to 0.7 mm; existing authored sizes are retained.

Advanced now reports rotating bezel diameter as a percentage of the case preview. In the supplied screenshot, 37.5/46 = 81.5%, whereas the selected midcase is 40 mm (37.5/40 = 93.75%). Case preview size does not resize purchased parts. Procedural case styling is illustrative and does not certify fit.

Right-hand catalogue and crown choices no longer preview on hover or single pointer click. Double-click previews; Enter/Space offer keyboard access. Apply remains explicit and retains compatibility/lock checks. Cancel restores the committed design. The option list scrolls as one panel so it remains reachable in short windows.

In 3D view, single-click crown did not create a preview; double-click onion crown did; Cancel removed it. Catalogue double-click created an incompatible preview with Apply correctly disabled. No browser errors observed. No claim of exhaustive GPU/performance benchmarking.
