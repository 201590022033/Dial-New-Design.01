# Watch Design Guidelines

## Version 3 Position

Version 3 treats watchmaking knowledge as a reusable library layered on top of the frozen engineering framework.

The application should guide users toward authentic, manufacturable watch design outcomes while preserving mathematical correctness.

## Non-Negotiable Principles

1. Authenticity first.
A dial should read like a professional watch product, not generic vector art.

2. Geometry through existing framework only.
Projection, profile, formatter, and rendering systems remain the source of mathematical truth.

3. Manufacturability is mandatory.
Design choices should be explainable against manufacturing capabilities with traceable confidence labels.

4. Professional restraint.
The system should encourage proven watch design patterns over arbitrary decoration.

## Family Guidance

### Pilot and Aviation

- Favor high-contrast typography and controlled surface noise.
- Prioritize railroad and instrument chapter ring compatibility.
- Preserve spacing for dense conversion and navigation scales.

### Chronograph

- Keep tachymeter/telemeter/pulsometer scales visually dominant when present.
- Avoid texture treatments that compete with dense timing numerals.
- Use chapter ring profiles with clear radial print margins.

### Dress

- Favor controlled negative space and premium marker furniture.
- Use applied assets only when supplier capabilities support assembly tolerances.
- Keep typography size above process minima for serif and ornate families.

### Dive and Military

- Prioritize lume area, marker separation, and minute readability.
- Use chapter rings and timers that maintain high legibility under low contrast.
- Prefer robust marker geometries that tolerate manufacturing variation.

## Component Library Intent

All user-facing design choices should map to reusable asset definitions:

- scale assets,
- chapter ring assets,
- marker assets,
- hand assets,
- material assets,
- typography assets.

Each asset should include compatibility metadata so recommendations are contextual instead of generic.

## Advisor Behavior

Recommendations should always answer:

1. Is this authentic for the selected watch family?
2. Is geometry still mathematically coherent?
3. Is the design likely manufacturable by selected supplier categories?
4. Does visual hierarchy remain professional?

Advisor responses should explain why and suggest concrete corrections.
